# DIFFVERS

サーバーやネットワークを監視するオープンソース（OSS）の統合監視ソフトウェアである「Zabbix」の更改作業を支援することを目的に、バージョン間の各種パラメータの差分を比較します。

demo page: https://main.ddwhimtre9vsm.amplifyapp.com/

※Chromeのみ動作確認済み。また、レスポンシブ対応はしておらず、スマートフォン、タブレットでの利用は考慮していません。

- ログイン用のサンプルユーザー
  - user: example@example.com
  - pass: P@ssw0rd


![Image](https://github.com/user-attachments/assets/13040e40-4af4-4ebb-b974-35022fb0c052)

- Process：パラメータの比較対象となるプロセスを指定します。
- Filter：リスト表示するパラメータの性質を指定します（バージョン間で異なっているもののみ表示、など）。
- Ver： パラメータのバージョンを指定します。
